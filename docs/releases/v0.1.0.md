## KubePrep 0.1.0

First public binary. This is a lab runner, not a CKA course — an experiment in
Go from someone studying for the exam.

You get a dedicated three-node `kind` cluster, a split terminal (scenario + a
real Lab Shell), and grading of **cluster state**, not the commands you typed.
The binary ships one lab: **First API Object** (`pod-creation`). Beginner, CKA,
and CKAD all play that lab today.

### Install

Archives for macOS and Linux (amd64 and arm64) are attached. Docker must already
be running.

```sh
tar -xzf kubeprep_0.1.0_Darwin_arm64.tar.gz   # pick your OS/arch
sudo mv kubeprep /usr/local/bin/
kubeprep --version
kubeprep doctor
kubeprep start --track=beginner
```
