## KubePrep 0.1.2 — Install from the right archive

0.1.1 told you to unpack `Darwin_arm64`. The files on the release are lowercase
(`darwin_arm64`, `linux_amd64`). Bash globs are case-sensitive, so that copy-paste
missed the download even when the archive was in the current directory.

This release adds `scripts/install.sh`. It maps `uname` (`x86_64` → `amd64`,
`aarch64` → `arm64`), verifies `checksums.txt`, and extracts into a temp directory
so `LICENSE` / `README.md` do not overwrite a checkout. bash and zsh download the
**same** file for a given machine; run the script with bash (`curl … | bash`),
not zsh. macOS vs Linux is the only download split.

Labs and CLI are unchanged from 0.1.1.

### Install

Docker must already be running.

```sh
curl -fsSL https://raw.githubusercontent.com/YakShavingCatHerder/kubeprep/main/scripts/install.sh | bash
kubeprep --version
kubeprep doctor
kubeprep start --track=beginner
```

Pin this tag with `KUBEPREP_VERSION=v0.1.2`. `PREFIX` and `--no-sudo` override
the install path.

| Host | Archive |
| --- | --- |
| macOS Apple Silicon | `kubeprep_0.1.2_darwin_arm64.tar.gz` |
| macOS Intel | `kubeprep_0.1.2_darwin_amd64.tar.gz` |
| Linux x86_64 | `kubeprep_0.1.2_linux_amd64.tar.gz` |
| Linux ARM | `kubeprep_0.1.2_linux_arm64.tar.gz` |

### Not in this release

- Exam mode
- A full CKA or CKAD playlist
- Windows
