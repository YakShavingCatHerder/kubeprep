## KubePrep 0.1.1 — Welcome path

0.1.0 shipped one lab. This release is the first path you can play through:
meet kubectl, create a Pod, inspect it, exec into it, write a manifest, then
review. CKA starts with a first Deployment. Same contract as before: real
`kubectl`, a dedicated `kind` cluster, grades **cluster state**.

The split UI is quieter. Scenario copy can paginate. Commands, diagrams, and
YAML render as distinct pane markup. Check feedback appears after F2, not as a
standing VALIDATION block.

### Install

bash and zsh download the same archive. Run the installer with bash
(`curl … | bash`), not zsh. macOS vs Linux picks the file:

| Host | Archive |
| --- | --- |
| macOS Apple Silicon | `kubeprep_0.1.1_darwin_arm64.tar.gz` |
| macOS Intel | `kubeprep_0.1.1_darwin_amd64.tar.gz` |
| Linux x86_64 | `kubeprep_0.1.1_linux_amd64.tar.gz` |
| Linux ARM | `kubeprep_0.1.1_linux_arm64.tar.gz` |

Docker must already be running.

```sh
curl -fsSL https://raw.githubusercontent.com/YakShavingCatHerder/kubeprep/main/scripts/install.sh | bash
kubeprep --version
kubeprep doctor
kubeprep start --track=beginner
```

### Beginner

- meet kubectl (`kubectl-basics`)
- create your first pod (`pod-creation`)
- inspect a running pod (`pod-inspection`)
- run commands inside a pod (`pod-exec`)
- create a pod from yaml (`manifest-basics`)
- Review the Kubernetes Foundations (`welcome-summary`)

Ungraded labs use F2 to continue. Graded labs use F2 to check the cluster.

### CKA / CKAD

- CKA: Create Your First Deployment (`deployment-basics`)
- CKAD: meet kubectl (`kubectl-basics`)

### Authoring

From a repository checkout: `kubeprep lab try`, `lab publish`, and
`lab validate`. See
[contribute/README.md](https://github.com/YakShavingCatHerder/kubeprep/blob/v0.1.1/contribute/README.md).

### Not in this release

- Exam mode
- A full CKA or CKAD playlist
- Windows
